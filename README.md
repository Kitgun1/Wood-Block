## 1. Общая архитектура и запуск

### 🚀 Запуск игры
* **Стартовая сцена**: `Assets/Wood Block/Scenes/BootScane.unity`
  > [!IMPORTANT]
  > Всегда запускайте игру с этой сцены. Она отвечает за инициализацию `Billings` (загрузку каталога продуктов из SDK Playgama Bridge) и отправку события готовности платформы (`GameReady`), после чего перенаправляет игрока в главное меню.
* **Главное меню**: `Assets/Wood Block/Scenes/Main Menu.unity`
* **Игровая сцена (Бесконечный режим / Базовый)**: `Assets/Wood Block/Scenes/Game.unity`
* **Сцены уровней**: Расположены в `Assets/Wood Block/Scenes/Levels/` (`Level1.unity`, `Level2.unity` и т.д.)

### 💾 Сохранение данных
Сохранения осуществляются через класс `DataSaver.cs` с использованием строковых ключей из `SaveKeys.cs`. Данные сохраняются локально.

## 2. Работа с уровнями (Создание и генерация)

Каждый уровень состоит из двух компонентов: **Карта блоков (Сетка)** и **Цели уровня (Квесты)**.

### Шаг 1: Создание структуры игрового поля (`LevelMap`)
Для создания карты блоков используется генератор тайлов:
1. Откройте сцену генерации или добавьте на сцену компонент [LevelGenerator](file:///d:/Projects/UnityProjects/Wood-Block/Assets/Wood%20Block/Scripts/Levels/LevelGenerator.cs).
2. Настройте игровое поле, расставив тайлы на компоненте `Tilemap` в Unity Editor.
3. В компоненте `LevelGenerator` укажите ссылку на этот `Tilemap`, настройте номер уровня в поле `Level`.
4. Нажмите кнопку **Generate** в инспекторе. 
5. Скрипт создаст ассет карты в папке `Assets/Wood Block/Configs/Maps/Level X.asset`. Это ScriptableObject типа `LevelMap`, хранящий список координат предзаполненных блоков.

### Шаг 2: Создание сцены уровня
Сцены уровней создаются на основе базовой сцены с помощью скрипта автоматизации [LevelCreater](file:///d:/Projects/UnityProjects/Wood-Block/Assets/Wood%20Block/Scripts/OnlyDeveloping/LevelCreater.cs):
1. Найдите объект с компонентом `LevelCreater` в редакторе (обычно на сцене генерации).
2. Укажите:
   * `Base Level Path`: путь к базовой сцене-шаблону (например, `Assets/Wood Block/Scenes/LevelBase.unity`).
   * `Save Path`: папку для сохранения уровней (`Assets/Wood Block/Scenes/Levels`).
   * `Max Level Count`: количество уровней для генерации.
3. Нажмите кнопку **Generate Level** в инспекторе. Скрипт автоматически продублирует базовую сцену под новыми номерами и настроит на них компонент [QuestManager](file:///d:/Projects/UnityProjects/Wood-Block/Assets/Wood%20Block/Scripts/QuestsGenerator/QuestManager.cs).
4. Добавьте созданные сцены уровней в **Build Settings** Unity в правильном порядке.
   * **Важное замечание**: Кнопка выбора уровня в меню загружает сцену по индексу `BuildIndex = НомерУровня + 2`. Убедитесь, что порядок сцен в Build Settings строго соответствует этому правилу.

### Шаг 3: Настройка целей (Квестов) уровня
За цели отвечает связка `QuestManager` и `QuestGenerator`:
* **Процедурная генерация целей**:
  Если в сохранениях нет предзаписанных целей, [QuestGenerator](file:///d:/Projects/UnityProjects/Wood-Block/Assets/Wood%20Block/Scripts/QuestsGenerator/QuestGenerator.cs) автоматически рассчитывает сложность целей исходя из номера уровня:
  * Целевое количество блоков увеличивается с каждым уровнем: `StartBlocks + (Level - 1) * BlocksIncrease`.
  * Шанс получить квест с ограничением по времени регулируется полем `TimedQuestChance` (в процентах).
* **Статические цели**:
  Вы можете преднастроить квесты вручную, сохранив их структуру `List<QuestData>` в сохранения по ключу `SaveKeys.LevelQuests`.

## 3. Система скинов (Добавление и настройка)

Скины делятся на два типа:
1. **Скин блоков** (`Skin`) — текстура для игровых ячеек (блоков).
2. **Скин фона** (`SkinBackground`) — пак текстур для оформления интерфейса (фон игрового поля, рамки ячеек, контейнеры блоков, кнопки и панели проигрыша).

### Как добавить новые скины в проект:
1. **Подготовка спрайтов**: Импортируйте ваши текстуры/спрайты в Unity.
2. **Настройка контейнера данных**: 
   * Найдите ассет базы скинов `SkinsData` (ScriptableObject) в проекте.
   * Откройте его в инспекторе. Он содержит два словаря `SerializedDictionary`:
     * `Background Skins` (ключ: строковый ID скина, значение: объект `SkinBackground` со ссылками на текстуры элементов интерфейса).
     * `Skins` (ключ: строковый ID скина, значение: `Skin` со ссылкой на спрайт блока).
   * Добавьте новый элемент, назначьте ему уникальный строковый ID (например, `neon_bg` или `wooden_skin`) и перетащите соответствующие спрайты.
3. **Отрисовка в игре**:
   * На игровых объектах и элементах интерфейса висит компонент [SkinAplayer](file:///d:/Projects/UnityProjects/Wood-Block/Assets/Wood%20Block/Scripts/Skins/SkinAplayer.cs).
   * Он считывает выбранный ID из сохранений (`SaveKeys.SelectedSkinId` / `SaveKeys.SelectedBackgroundId`), запрашивает скин из `SkinsData` и автоматически подставляет нужные спрайты в `SpriteRenderer` или `Image` в зависимости от выбранного `SkinType` на компоненте.

## 4. Внутриигровые покупки и биллинг

Для распространения скинов в магазине используется интеграция с SDK Playgama Bridge через класс [Billings](file:///d:/Projects/UnityProjects/Wood-Block/Assets/AVESdk/Runtime/Scripts/Billings/Billings.cs).

### Настройка магазина скинов:
Скины автоматически подгружаются в магазин из каталога продуктов Playgama. 

1. **Создание продукта в BillingsSettings**:
   * Найдите ассет настроек биллинга `BillingsSettings` (загружается через Addressables по ключу `"BillingsSettings"`).
   * В словаре `Catalog Products` зарегистрируйте товар:
     * Ключ: ID продукта, совпадающий с ID из Playgama консоли (например, `neon_bg_product` или `skin_wood`).
     * Значение (`ProductSetting`): русское и английское название товара (`RuTitle`/`EnTitle`) и его иконка для отображения в магазине.
2. **Настройка типа разблокировки в магазине**:
   В компоненте [ShopSystem](file:///d:/Projects/UnityProjects/Wood-Block/Assets/Wood%20Block/Scripts/Shop/ShopSystem.cs) настройте поведение скинов:
   * **Покупка за валюту (Реальные деньги / In-App)**: Все скины по умолчанию считаются платными (`WaysToUnlockSkin.BuyForCurrencie`) и покупаются через вызов платежного шлюза Playgama (`Billings.PurchaseProduct`).
   * **Получение за рекламу**: Добавьте ID скина в список `_skinIdThatGetForAdd`. При попытке получить этот скин будет запускаться показ Reward-рекламы.
   * **Получение за уровни**: Добавьте запись в словарь `_skinIdThatGetForLevels` (где ключ — ID скина, а значение — номер уровня). Скин разблокируется автоматически, когда игрок дойдет до указанного уровня.
3. **Процесс покупки**:
   * Игрок нажимает «Купить».
   * Магазин вызывает `Billings.PurchaseProduct(id, ...)` -> отправляется запрос в Playgama SDK.
   * При успешном завершении транзакции вызывается коллбек подтверждения покупки `Billings.ConsumeProduct(id, ...)`. После успешного подтверждения скин помечается как купленный в сохранениях и автоматически применяется.
